---
title: "Number Input"
description: "The Number Input element collects a number, whole or decimal, and keeps the form from being submitted while the field holds anything else."
---

The Number Input element is built for numeric data: quantities, prices, scores, percentages or any other number. It accepts whole numbers and decimals.

Like the Text Input, it supports regex-based validation, default values, read-only and disabled modes, and full runtime manipulation via the Procesio Forms data model.

## Entering a number [#entering-a-number]

The field accepts whatever the person types, and checks it as they type:

- A whole number such as `42`, a negative number such as `-8`, or a decimal with a dot, such as `1234.5`, is a number.
- On phones and tablets the field opens a keyboard for numbers.
- While the field holds text that is not a number, such as `abc`, the form's **Submit** button is disabled and nothing is sent. Hover the disabled **Submit** button to see the reason: *"Enter a number, for example 1234.5."* As soon as the field holds a number again, **Submit** is enabled.

An empty field does not block **Submit**. Turn on **Required** to make a value mandatory.

## Key Use Cases

•        Quantity fields, pricing inputs, age or score collection

•        Dynamically updating a total or calculated field at runtime by setting value

•        Setting min/max constraints via regex or external form logic

•        Locking a numeric field after a process step by toggling readonly at runtime

•        Pre-filling budget, quota, or threshold values from process variables on form load

## Runtime API — Attributes in Procesio Forms

*All attributes below are accessible and modifiable at runtime via the element's data model in Procesio Forms — on any available event such as onLoad, onChange, or custom triggers.*



| **API Name**     | **Description**                                      | **Type**       | **Default** | **Notes** |
| ---------------- | ---------------------------------------------------- | -------------- | ----------- | --------- |
| **label**        | Display label shown above the input field            | string         | —           | —         |
| **placeholder**  | Hint text shown inside the empty field               | string         | —           | —         |
| **tooltip**      | Help text shown alongside the label                  | string         | —           | —         |
| **infotext**     | Supplementary info displayed below the input         | string         | —           | —         |
| **defaultvalue** | Initial value when the form loads                    | number\|string | —           | —         |
| **value**        | Current runtime value — read or set programmatically | number\|string | —           | —         |
| **readonly**     | If true, users can view but not edit the value       | boolean        | false       | —         |
| **disabled**     | If true, the field is fully non-interactive          | boolean        | false       | —         |
| **visible**      | Controls element visibility                          | boolean        | true        | —         |
| **name**         | Unique name for referencing in logic/events          | string         | —           | —         |
| **id**           | Unique element ID                                    | string         | —           | —         |
| **required**     | Marks the field as mandatory on submit               | boolean        | false       | —         |
| **regex**        | Regex pattern for custom numeric validation          | string\|null   | —           | —         |
