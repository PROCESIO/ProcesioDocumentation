Everything you build in PROCESIO starts here. The **Process Designer** is the canvas where you create and run automations, the **Data Model Designer** defines the shape of the data they carry, and the **Document Designer** turns templates into generated documents. **Working with Credentials** keeps the secrets your processes use in one place.
