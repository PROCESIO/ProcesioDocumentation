An SMTP Inbound credential holds the connection to the mail server you read emails from. The [Read Mailbox](/how-to/read-mailbox) and [Read Mailbox V2](/how-to/read-mailbox-v2) actions use it. To create one, follow [Create a credential](/working-with-credentials#create-a-credential) and fill in the fields below.

### Incoming email configuration

1. **Server Name/IP**: fill in the incoming mail server, for example mail.example.com  (replacing example.com with your actual domain name).
2. **Protocol type**: select IMAP or POP3. IMAP maintains the emails in your account, POP3 removes them once the operation is completed.
3. **Port number**: fill in the incoming server port.
4. **Encryption**: None, TLS or Auto.
5. **Username**: enter your username.
6. **Password**: enter the associated password.
7. **Test Connection**: once all mandatory fields have values, you can test the configuration.
8. **Save&#x20;**&#x74;he configuration.
