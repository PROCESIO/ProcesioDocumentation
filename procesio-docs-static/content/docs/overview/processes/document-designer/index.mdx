---

The **Document Designer** lets you build your own document templates — invoices, contracts, reports, notification emails, anything you print or send out — and fill them automatically with the data flowing through your processes. Lay out the text, images and tables once; every run of your process produces a new document with that run's own data dropped in.

It's two halves of one workflow:

1. **[Create a document template](/document-template-creation)** — design the document in the built-in editor and mark the spots that should change with **variables**.
2. **[Use the template](/using-the-template)** in a process with the **[Generate Document](/how-to/generate-document)** action, mapping your process's data onto those variables, to produce a PDF or HTML file (or both) on every run.
