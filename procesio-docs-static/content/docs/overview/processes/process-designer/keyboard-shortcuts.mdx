The Process Designer has a small set of keyboard shortcuts. **Some of them are
configurable**, so if one clashes with something your browser or your operating system
already uses, you can change it.

**Configurable** (under **Preferences → HotKeys**): Save process, Open variables
selector, Beautify content in editor, and Enlarge / Close input box.
**Fixed**: copy and paste, Ctrl+click to add to the selection, and Delete.

<Callout type="info">
  Verified on 4 November 2026. The combinations below are the defaults.
</Callout>

## The shortcuts [#the-shortcuts]

| Shortcut                                     | What it does                                                                      |
| -------------------------------------------- | --------------------------------------------------------------------------------- |
| **Ctrl + S** *(Cmd + S on a Mac)*            | **Save process.** The same as clicking **Save** in the topbar.                      |
| **Ctrl + I** *(Cmd + I on a Mac)*            | **Open the variables selector** inside a code editor or an input, to insert a process variable instead of typing its name. |
| **Shift + Alt + F**                          | **Beautify the content in the editor** — reformats and re-indents what is in the code editor.                              |
| **Esc** *(in an input)*                      | **Enlarge an input box, and close it again** — toggles the full-screen editor on the input you are in.                      |
| **Esc** *(with a right-click menu open)*     | **Close the right-click menu** — on an action, on an action inside a **For Each**, or on a canvas shape.                     |
| **Ctrl + C** / **Ctrl + V** *(Cmd on a Mac)* | **Copy and paste actions** on the canvas. See [Platform Tricks](/platform-tricks#copying-and-pasting-actions).              |
| **Ctrl + click** *(Cmd + click on a Mac)*    | **Add an action to the selection**, to move several at once.                        |
| **Delete**                                   | **Delete** what is selected on the canvas.                                          |

<Callout type="info">
  **Shift + Alt + F** is the code editor's own formatting command, so it is the same
  combination on every platform — it does not become Cmd on a Mac.
</Callout>

## Change a shortcut [#change-a-shortcut]

1. Click your **user profile** icon in the topbar.
2. Open **Preferences**, then **HotKeys**.
3. In the **PROCESIO Hotkeys** panel, click the shortcut you want to change and
   press the new combination.
4. **Save**.

Each shortcut is listed with the keys currently assigned to it, and most come with a
short animation showing what it does — the quickest way to tell them apart.

## Shortcuts that need the canvas focused [#canvas-focus]

**Copy**, **paste** and **Delete** act on the canvas, so the canvas has to have the
keyboard focus — click an empty part of it first. If you have just typed in a
properties panel, in an input or in the toolbox search box, the focus is still there
and these shortcuts do nothing. Nothing is lost; click the canvas and press them
again.

**Esc is the exception.** It closes an open right-click menu wherever the keyboard
focus happens to be, so you never have to click the canvas first to dismiss a menu.
