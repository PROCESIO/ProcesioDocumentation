---
title: "Automation"
icon: "🧬"
description: "Run processes without clicking Run — on a schedule, from a webhook, or through the API."
---

A process becomes automation when something triggers it for you. **Schedules** run processes at set times, **Webhooks** let external systems start them the moment something happens, and **API Keys** authenticate machine-to-machine calls to the PROCESIO API.
