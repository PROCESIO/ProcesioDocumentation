The actions in the **Scripting** folder of the Process Designer toolbox run code that you write. Pass process variables into the code, then map the outputs back into the process.

| Action | What it does |
| --- | --- |
| [Node](/how-to/node) | Runs JavaScript on Node.js, with libraries loaded by `require`. Outputs: Single Result, List Result, Stdout, Error. |
| [Python](/how-to/python) | Runs Python code, with libraries such as pandas and NumPy. Outputs: Single Result, List Result, Stdout, Error. |
| [Ruby](/how-to/ruby) | Runs Ruby code, with gems such as Nokogiri and Liquid. Outputs: Single Result, List Result, Stdout, Error. |
| [Javascript](/how-to/javascript) | Runs JavaScript and returns the value passed to `setOutput` in a single Output. |
| [CURL](/how-to/curl) | Runs a curl command and returns the HTTP status, the response body and any curl error. |

<Callout type="info">
In Node, Python and Ruby, an error in your code does not stop the process: the step finishes and the **Error** output holds the message. Check **Error** with a [Decisional](/how-to/decisional) before you use the result.
</Callout>
