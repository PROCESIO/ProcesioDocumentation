**Get Month** returns the month of a date as a number from `1` (January) to `12` (December). Use it to group records by month or to check which period a date belongs to.

## Add the action [#add-the-action]
In the Process Designer toolbox, open **DateTime** and pick **Get Month** (or type *Get Month* in the search box).

![The Get Month action properties: Date and Month](/images/docs/actions/datetime-get-month/panel.png)

## Inputs and outputs [#inputs-and-outputs]
| Field | Direction | Type | Required | What to put / what you get |
| --- | --- | --- | --- | --- |
| **Date** | Input | Date and time | Yes | The date and time to read the month from. |
| **Month** | Output | Integer | Yes | The month. |

## Example [#example]
| Date | Month |
| --- | --- |
| `2024-02-29` | `2` |
| `05/10/2010` | `5` |

## Good to know [#good-to-know]
- **Time zone:** a value that carries a UTC offset (for example `2025-01-01T01:00:00+02:00`) is first converted to UTC, and the part is read from the UTC value. A value without an offset, or ending in `Z`, is used as it is.
- A date written with slashes, like `05/10/2010`, is read month first (US order): month `5`, day `10`. Use the `yyyy-MM-dd` form, or [String To DateTime](/how-to/string-to-datetime) with an explicit format, to avoid any doubt.
- To get the month name instead of its number, use [Format DateTime](/how-to/format-datetime) with the format `MMMM`.
- An empty or invalid **Date** (for example `2023-02-29` or `not a date`) stops the step with an error.
