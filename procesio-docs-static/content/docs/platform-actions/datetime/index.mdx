The **DateTime** folder holds the actions that work with dates and times.

<Callout type="info">
PROCESIO works in **UTC**. **Today** and **UTC Now** return the UTC date and time, and a value that carries an offset (for example `+02:00`) is converted to UTC before an action uses it. To show a time in a local time zone, use [Timezone Converter](/how-to/timezone-converter).
</Callout>

| Action | What it does |
| --- | --- |
| [Today](/how-to/today) | Returns today's date (UTC), at midnight. |
| [UTC Now](/how-to/utc-now) | Returns the current date and time in UTC. |
| [Is Weekend](/how-to/is-weekend) | Checks whether a date is a Saturday or a Sunday. |
| [Is Weekday](/how-to/is-weekday) | Checks whether a date is between Monday and Friday. |
| [Get Year](/how-to/get-year) | Returns the year of a date. |
| [Get Month](/how-to/get-month) | Returns the month of a date, 1 to 12. |
| [Get Day](/how-to/get-day) | Returns the day of the month, 1 to 31. |
| [Get Hour](/how-to/get-hour) | Returns the hour, 0 to 23. |
| [Get Minute](/how-to/get-minute) | Returns the minute, 0 to 59. |
| [Get Week Number](/how-to/get-week-number) | Returns the week of the year. |
| [Get Day Of Week](/how-to/get-day-of-week) | Returns the day of the week as a number. |
| [Update DateTime](/how-to/update-datetime) | Adds or subtracts years, months, days, hours, minutes or seconds. |
| [String To DateTime](/how-to/string-to-datetime) | Reads a date from text, with a format you give. |
| [Format DateTime](/how-to/format-datetime) | Writes a date as text, in a format you write. |
| [DateTime To String](/how-to/datetime-to-string) | Writes a date as text, in a standard format you pick. |
| [Date Difference](/how-to/date-difference) | Days, weeks, months, quarters or years between two dates. |
| [Time Difference](/how-to/time-difference) | Hours, minutes or seconds between two dates and times. |
