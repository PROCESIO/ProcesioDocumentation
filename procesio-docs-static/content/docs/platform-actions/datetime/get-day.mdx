**Get Day** returns the day of the month of a date, from `1` to `31`. Use it, for example, to run a step only on the first day of the month.

## Add the action [#add-the-action]
In the Process Designer toolbox, open **DateTime** and pick **Get Day** (or type *Get Day* in the search box).

![The Get Day action properties: Date and Day](/images/docs/actions/datetime-get-day/panel.png)

## Inputs and outputs [#inputs-and-outputs]
| Field | Direction | Type | Required | What to put / what you get |
| --- | --- | --- | --- | --- |
| **Date** | Input | Date and time | Yes | The date and time to read the day of the month from. |
| **Day** | Output | Integer | Yes | The day of the month. |

## Example [#example]
| Date | Day |
| --- | --- |
| `2024-02-29` | `29` |
| `05/10/2010` | `10` |
| `2024-03-01T00:30:00+02:00` | `29` (the value is 2024-02-29 22:30 in UTC) |

## Good to know [#good-to-know]
- **Time zone:** a value that carries a UTC offset (for example `2025-01-01T01:00:00+02:00`) is first converted to UTC, and the part is read from the UTC value. A value without an offset, or ending in `Z`, is used as it is.
- This is the day of the **month**. For the day of the **week** (Monday, Tuesday…), use [Get Day Of Week](/how-to/get-day-of-week).
- A date written with slashes, like `05/10/2010`, is read month first (US order), so the day is `10`.
- An empty or invalid **Date** (for example `2023-02-29` or `not a date`) stops the step with an error.
