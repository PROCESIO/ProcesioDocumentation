title: "DateTime To String"
icon: "📕"
description: "Turns a date and time into text, using one of the standard formats from a list."
---

**DateTime To String** writes a Date and time value as text in one of the common standard shapes, which you pick from a list: short date, long date, ISO 8601, RFC 1123 and others. The **Language** decides the order of day and month and the names of months and days. If you need your own shape, use [Format DateTime](/how-to/format-datetime).

## Add the action [#add-the-action]
In the Process Designer toolbox, open **DateTime** and pick **DateTime To String** (or type *DateTime To String* in the search box).

![The DateTime To String action properties: Datetime, Language, Format and Formatted Datetime](/images/docs/actions/datetime-datetime-to-string/panel.png)

## Inputs and outputs [#inputs-and-outputs]
| Field | Direction | Type | Required | What to put / what you get |
| --- | --- | --- | --- | --- |
| **Datetime** | Input | Date and time | Yes | The date and time to write as text. |
| **Language** | Input | Option list | Yes | Options: Română (RO), English (UK), English (US), Ελληνικά (GR), Español (ES), 中国人 (CN), Pусский (RU), Deutsch (DE), हिन्दी (IN), عربي (UAE), Français (FR). |
| **Format** | Input | Option list | Yes | The shape of the text. Each option shows a sample in English (US). See the table below. |
| **Formatted Datetime** | Output | Text | Yes | The date as text. |

## Example [#example]
All rows use the **Datetime** `2024-06-15T13:45:30`. The **Format** column shows the option as it appears in the list.

| Format option | Language | Formatted Datetime |
| --- | --- | --- |
| 6/15/2009 | English (US) | `6/15/2024` |
| 6/15/2009 | English (UK) | `15/06/2024` |
| Monday, June 15, 2009 | Deutsch (DE) | `Samstag, 15. Juni 2024` |
| Monday, June 15, 2009 1:45:30 PM | English (US) | `Saturday, June 15, 2024 1:45:30 PM` |
| 6/15/2009 1:45 PM | English (US) | `6/15/2024 1:45 PM` |
| June 15 | English (US) | `June 15` |
| June 2009 | Română (RO) | `iunie 2024` |
| 1:45:30 PM | English (US) | `1:45:30 PM` |
| 2009-06-15T20:45:30+00:00 | English (US) | `2024-06-15T13:45:30+00:00` |
| Mon, 15 Jun 2009 20:45:30 GMT | English (US) | `Sat, 15 Jun 2024 13:45:30 GMT` |
| 2009-06-15T13:45:30 | English (US) | `2024-06-15T13:45:30` |
| 2009-06-15 13:45:30Z | English (US) | `2024-06-15 13:45:30Z` |
| Monday, June 15, 2009 8:45:30 PM | English (US) | `Saturday, June 15, 2024 1:45:30 PM` |

The list also has **Monday, June 15, 2009 1:45 PM** (long date, short time), **6/15/2009 1:45:30 PM** (short date, long time) and **1:45 PM** (short time).

## Good to know [#good-to-know]
- **Day and month order follows the Language**, not the sample in the option name: the *6/15/2009* option gives `15/06/2024` in English (UK).
- **For APIs and databases**, pick a fixed, language-neutral shape: *2009-06-15T13:45:30* (sortable), *2009-06-15T20:45:30+00:00* (ISO 8601 with offset) or *Mon, 15 Jun 2009 20:45:30 GMT* (RFC 1123).
- **Time zone:** the action does not convert the time. A value without an offset is treated as UTC, so the ISO 8601 option adds `+00:00` and the RFC 1123 option adds `GMT`. A value with an offset is converted to UTC when it enters the action.
