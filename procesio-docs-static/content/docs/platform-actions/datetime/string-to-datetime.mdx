title: "String To DateTime"
icon: "📕"
description: "Reads a date and time from text, using the format and language you give."
---

**String To DateTime** turns text such as `15/06/2024 13:45` or `15 iunie 2024` into a Date and time value that the other DateTime actions can work with. You tell it how the text is written (the **Format**) and which language month and day names are in. Use it for dates that arrive as text: from an API, an email, a CSV or Excel file, or a form.

## Add the action [#add-the-action]
In the Process Designer toolbox, open **DateTime** and pick **String To DateTime** (or type *String To DateTime* in the search box).

![The String To DateTime action properties: String, Language, Format, Format List, Datetime and Exact Format Parsing](/images/docs/actions/datetime-string-to-datetime/panel.png)

## Inputs and outputs [#inputs-and-outputs]
| Field | Direction | Type | Required | What to put / what you get |
| --- | --- | --- | --- | --- |
| **String** | Input | Text | Yes | The text that contains the date. |
| **Language** | Input | Option list | Yes | The language of month and day names in the text, and the default date order. Options: Română (RO), English (UK), English (US), Ελληνικά (GR), Español (ES), 中国人 (CN), Pусский (RU), Deutsch (DE), हिन्दी (IN), عربي (UAE), Français (FR). Default English (US). |
| **Format** | Input | Text | No* | How the text is written, for example `dd/MM/yyyy HH:mm`. |
| **Format List** | Input | List of Text | No* | Several formats to try, when the text can come in more than one shape. Map a list variable here. |
| **Datetime** | Output | Date and time | Yes | The date and time read from the text. |
| **Exact Format Parsing** | Output | Boolean (true/false) | No | `true` when the text matched your **Format** or one of the **Format List** entries. `false` when it did not match and the action read it in the language's usual way instead (see *Good to know*). |

\* Fill in **Format** or **Format List**. If both are empty, the step stops with `Format Error: Please provide a non-empty Format !`. When **Format List** has at least one entry, **Format** is ignored.

## Format codes [#format-codes]
The most used codes (they are case-sensitive):

| Code | Meaning | Example |
| --- | --- | --- |
| `yyyy` | Year, 4 digits | `2024` |
| `MM` / `M` | Month, 2 digits / 1–2 digits | `06` / `6` |
| `MMM` / `MMMM` | Month name, short / full, in the chosen **Language** | `Jun` / `June`, `iunie` |
| `dd` / `d` | Day of the month | `05` / `5` |
| `HH` | Hour, 24-hour clock | `13` |
| `hh` + `tt` | Hour, 12-hour clock, with AM/PM | `01 PM` |
| `mm` | Minutes | `45` |
| `ss` | Seconds | `30` |
| `zzz` | UTC offset | `+03:00` |
| `'text'` | Fixed text, copied as it is | `'Generated on '` |

The full list is in Microsoft's [custom date and time format strings](https://learn.microsoft.com/dotnet/standard/base-types/custom-date-and-time-format-strings).

## Example [#example]
| String | Language | Format / Format List | Datetime | Exact Format Parsing |
| --- | --- | --- | --- | --- |
| `15/06/2024 13:45` | English (UK) | `dd/MM/yyyy HH:mm` | `2024-06-15T13:45:00` | `true` |
| `15 iunie 2024` | Română (RO) | `dd MMMM yyyy` | `2024-06-15T00:00:00` | `true` |
| `06/15/2024 01:45 PM` | English (US) | `MM/dd/yyyy hh:mm tt` | `2024-06-15T13:45:00` | `true` |
| `Generated on 2026-02-11 14:35.` | English (US) | `'Generated on 'yyyy-MM-dd HH:mm'.'` | `2026-02-11T14:35:00` | `true` |
| `2024.06.15` | English (US) | Format List `["dd/MM/yyyy", "yyyy.MM.dd"]` | `2024-06-15T00:00:00` | `true` |
| `2024-06-15 13:45 +03:00` | English (US) | `yyyy-MM-dd HH:mm zzz` | `2024-06-15T10:45:00+00:00` | `true` |
| `2024-06-15 13:45` | English (US) | `dd/MM/yyyy` (does not match) | `2024-06-15T13:45:00` | `false` |
| `15 iunie 2024` | English (US) | `dd MMMM yyyy` | step fails: `Parsing Error: Wrong format / Wrong language, unable to parse => 15 iunie 2024` | |
| `31/02/2024` | English (UK) | `dd/MM/yyyy` | step fails: no 31 February | |

## Good to know [#good-to-know]
- **Fallback when the format does not match.** If the text does not match your format, the action still tries to read it the usual way for the chosen **Language**. If that works, you get a date and **Exact Format Parsing** is `false`. Check that output when the order of day and month matters: with the fallback, `05/10/2010` is read as 10 May 2010 in English (US) and as 5 October 2010 in English (UK). If the fallback fails too, the step stops with the *Parsing Error* above.
- **Invalid dates are refused**: `31/02/2024` or `29/02/2023` stop the step. An empty **String** stops it too.
- **Fixed text must be in single quotes.** Letters such as `d`, `M`, `y`, `h`, `m`, `s`, `t` are format codes. Write words that are part of the text inside `'…'`, as in the *Generated on* example.
- **Hours:** use `HH` for 0–23 and `hh` with `tt` for 1–12 with AM/PM. Mixing them up gives wrong times or a parsing error.
- **Time zone:** text with an offset (`+03:00`) is converted to UTC. Text without an offset is kept as it is, with no time zone.
- With **Format List**, the text only has to match one of the formats.
