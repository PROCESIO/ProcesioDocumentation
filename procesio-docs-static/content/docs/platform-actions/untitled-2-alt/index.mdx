The **HTML** folder of the Process Designer toolbox holds the actions that check, clean and edit HTML, for example the body of an email or a document template.

| Action | What it does |
| --- | --- |
| [Is Valid](/how-to/html-is-valid) | Checks that every tag is properly closed and nested (the step fails when it is not). |
| [Sanitizer](/how-to/html-sanitizer) | Removes scripts and other unsafe content from HTML, and can encode the result. |
| [HTML Manipulation](/how-to/html-manipulation) | Sets an attribute on, or adds a child element to, the element an XPath selects. |

To convert HTML, see the **Converters** folder: [HTML To JSON](/how-to/html-to-json), [JSON To HTML](/how-to/json-to-html) and [HTML To PDF](/how-to/html-to-pdf).
