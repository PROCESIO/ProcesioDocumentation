The **Numerical** folder holds the actions that calculate with numbers.

| Action | What it does |
| --- | --- |
| [Add](/how-to/add) | Adds two numbers. |
| [Subtract](/how-to/substract) | Subtracts one number from another. |
| [Modulo](/how-to/modulo) | Returns the remainder of dividing two whole numbers. |
| [Divide](/how-to/divide) | Divides one number by another. |
| [Multiply](/how-to/multiply) | Multiplies two numbers. |
| [Round Up](/how-to/round-up) | Rounds a number up to the decimals you choose. |
| [Round](/how-to/round) | Rounds a number to the nearest value with the decimals you choose. |
| [Round Down](/how-to/round-down) | Rounds a number down to the decimals you choose. |
| [String To Number](/how-to/parse-number) | Reads a number from text. |

<Callout type="info">
Write decimals with a dot (`3.14`). In **Add**, **Subtract**, **Multiply**, **Divide** and **String To Number** a comma is read as a thousands separator, so `1,5` counts as `15`.
</Callout>
