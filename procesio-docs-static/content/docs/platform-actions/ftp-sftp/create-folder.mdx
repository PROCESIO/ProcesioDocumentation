**Create Folder** creates a new folder on your SFTP or FTP server. Use it to prepare a destination before you upload or move files into it, for example one folder per day or per customer.

## Before you start [#before-you-start]
The action connects through an **FTP** credential that you create once in the **Credential Manager** (host, port, protocol FTP or SFTP, an optional **Directory path**, and a user name with a password or a key file). See [FTP Credential](/ftp-credential).

## Add the action [#add-the-action]
In the Process Designer toolbox, open **SFTP** and pick **Create Folder** (or type *Create Folder* in the search box).

![The Create Folder action properties: Select SFTP credentials, Source Folder, Folder Name and Result](/images/docs/actions/sftp-create-folder/panel.png)

## Inputs and outputs [#inputs-and-outputs]
| Field | Direction | Type | Required | What to put / what you get |
| --- | --- | --- | --- | --- |
| **Select SFTP credentials** | Input | FTP credential | Yes | The credential of the server. |
| **Source Folder** | Input | Text | No | An **existing** folder to create the new folder in, relative to the credential's **Directory path**. Leave empty for the root folder. |
| **Folder Name** | Input | Text | Yes | The name of the new folder. It can also be a path, such as `2026/11/10`: every missing level is created. |
| **Result** | Output | Boolean | Yes | `true` if the folder was created or already exists, `false` if not. |

## Examples [#examples]
Measured on an SFTP server where the folder `CFTEST1` already contained `aaa/bbb`:

| Source Folder | Folder Name | Result | What happened on the server |
| --- | --- | --- | --- |
| `CFTEST1` | `aaa/bbb/ccc/ddd` | `true` | Only the missing levels, `ccc` and `ccc/ddd`, were created inside `CFTEST1/aaa/bbb`. |
| `CFTEST1` | `aaa/bbb/ccc/ddd` (second run) | `true` | Nothing: the folders already existed. |
| `CFTEST1/aaa` | `bbb/ccc2` | `true` | `ccc2` was created inside `CFTEST1/aaa/bbb`. |
| `CFTEST1/nosuch1/nosuch2` | `leaf` | `false` | Nothing: **Source Folder** doesn't exist. |

## Good to know [#good-to-know]
- **Put the path in Folder Name, not in Source Folder.** Missing levels are created only when they are part of **Folder Name**. If **Source Folder** doesn't exist, **Result** is `false` and nothing is created, without an error.
- **Paths are relative to the credential's Directory path.** If the credential points to `/home/data`, write `exports`, not `/home/data/exports`. Repeating the Directory path makes the action look for `/home/data/home/data/exports` and return `false`.
- Both `/` and `\` separate levels in **Folder Name**. Leading, trailing and double separators are ignored.
- Running the action again on an existing folder returns `true`, so it is safe to run on every process run. `true` is also returned when a **file** with that name already exists, so don't use **Result** to tell a folder from a file.
- If one level can't be created, the levels created before it stay on the server and **Result** is `false`.
- Names are case-sensitive on most SFTP servers: `Reports` is created next to `reports`, not inside it. Spaces are kept as part of the name.
- If the server returns an error, the step fails with *"Error while trying to create folder"*.
