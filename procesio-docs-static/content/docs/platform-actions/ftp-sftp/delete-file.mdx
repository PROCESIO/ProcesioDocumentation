**Delete File** removes one file from your SFTP or FTP server, for example after you have downloaded and processed it.

## Before you start [#before-you-start]
The action connects through an **FTP** credential that you create once in the **Credential Manager** (host, port, protocol FTP or SFTP, an optional **Directory path**, and a user name with a password or a key file). See [FTP Credential](/ftp-credential).

## Add the action [#add-the-action]
In the Process Designer toolbox, open **SFTP** and pick **Delete File** (or type *Delete File* in the search box).

![The Delete File action properties: Select SFTP credentials, Folder Path, File Name and Result](/images/docs/actions/sftp-delete-file/panel.png)

## Inputs and outputs [#inputs-and-outputs]
| Field | Direction | Type | Required | What to put / what you get |
| --- | --- | --- | --- | --- |
| **Select SFTP credentials** | Input | FTP credential | Yes | The credential of the server. |
| **Folder Path** | Input | Text | No | The folder that holds the file, relative to the credential's **Directory path**. Leave empty for the root folder. |
| **File Name** | Input | Text | No | The name of the file to delete, with its extension. |
| **Result** | Output | Boolean | Yes | `true` if the file was deleted, `false` if not. |

## Example [#example]
**Folder Path** `inbox`, **File Name** `order-17.csv` → `inbox/order-17.csv` is removed and **Result** is `true`.

## Good to know [#good-to-know]
- The deletion can't be undone.
- **File Name** isn't marked as required in the panel, but you need it: without a name there is nothing to delete.
- If the server returns an error, the step fails with *"Error while trying to delete file"*.
- To delete several files at once, use [Delete Bulk](/how-to/sftp-delete-bulk). To delete a folder with everything in it, use [Delete Folder](/how-to/delete-folder).
