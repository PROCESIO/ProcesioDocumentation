**Upload File** writes the file held in a File variable to a folder on your SFTP or FTP server. Use it to deliver a generated report, a form attachment or a converted document to a partner's server.

## Before you start [#before-you-start]
The action connects through an **FTP** credential that you create once in the **Credential Manager** (host, port, protocol FTP or SFTP, an optional **Directory path**, and a user name with a password or a key file). See [FTP Credential](/ftp-credential).

## Add the action [#add-the-action]
In the Process Designer toolbox, open **SFTP** and pick **Upload File** (or type *Upload File* in the search box).

![The Upload File action properties: Select SFTP credentials, Input File, Target Folder and Result](/images/docs/actions/sftp-upload-file/panel.png)

## Inputs and outputs [#inputs-and-outputs]
| Field | Direction | Type | Required | What to put / what you get |
| --- | --- | --- | --- | --- |
| **Select SFTP credentials** | Input | FTP credential | Yes | The credential of the server to write to. |
| **Input File** | Input | File | Yes | The File variable that holds the file to upload. The file keeps its name. |
| **Target Folder** | Input | Text | Yes | The folder to upload into, relative to the credential's **Directory path**, for example `outbox/2026`. |
| **Result** | Output | Boolean | Yes | `true` if the file was uploaded, `false` if not. |

## Example [#example]
**Input File** holding `report.pdf`, **Target Folder** `outbox` → the server now has `outbox/report.pdf` and **Result** is `true`.

## Good to know [#good-to-know]
- Files up to 1 GB are supported.
- Paths are relative to the **Directory path** set in the credential. Don't repeat that path in **Target Folder**.
- If the upload fails with an error from the server, the step fails with *"Error while trying to upload file to folder."*
- To upload several files in one step, use [Upload Bulk](/how-to/sftp-upload-bulk).
