title: "Move File"

description: "Moves a file to another folder on the same SFTP or FTP server, or to another server."
---

**Move File** moves one file from a folder to another folder. The destination can be on the same server or on a different server, so you can also use it to transfer a file between two SFTP or FTP servers.

## Before you start [#before-you-start]
The action connects through an **FTP** credential that you create once in the **Credential Manager** (host, port, protocol FTP or SFTP, an optional **Directory path**, and a user name with a password or a key file). See [FTP Credential](/ftp-credential). For a move between two servers, you need one credential for each.

## Add the action [#add-the-action]
In the Process Designer toolbox, open **SFTP** and pick **Move File** (or type *Move File* in the search box).

![The Move File action properties: From SFTP credentials, From Folder, File Name, To SFTP credentials, To Folder and Result](/images/docs/actions/sftp-move-file/panel.png)

## Inputs and outputs [#inputs-and-outputs]
| Field | Direction | Type | Required | What to put / what you get |
| --- | --- | --- | --- | --- |
| **From SFTP credentials** | Input | FTP credential | Yes | The credential of the server where the file is now. |
| **From Folder** | Input | Text | No | The folder that holds the file. Leave empty for the root folder. |
| **File Name** | Input | Text | Yes | The name of the file to move, with its extension. |
| **To SFTP credentials** | Input | FTP credential | No | The credential of the destination server. Leave empty to stay on the same server. |
| **To Folder** | Input | Text | No | The destination folder. Leave empty for the root folder. |
| **Result** | Output | Boolean | Yes | `true` if the file was moved, `false` if not. |

## Example [#example]
**From Folder** `inbox`, **File Name** `order-17.csv`, **To Folder** `processed`, **To SFTP credentials** empty → the file is now `processed/order-17.csv` on the same server and **Result** is `true`.

## Good to know [#good-to-know]
- The move works in three steps: download the file, upload it to the destination, then delete the original. The original is deleted only after the upload succeeded.
- If the file can't be found, **Result** is `false` and nothing changes.
- If the upload works but the original can't be deleted, the file exists in both places and **Result** is `false`.
- The file keeps its name. To rename it, use [Rename File/Folder](/how-to/rename-file-folder) before or after.
- Paths are relative to the **Directory path** of each credential.
- An error from the server makes the step fail with *"Error while trying to move file."*
