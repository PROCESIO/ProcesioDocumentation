---
title: "SQL"
icon: "📁"
description: "Run SQL queries and commands against a SQL Server or MySQL database."
---

Two actions, both configured with a database credential:

| Action | What it does |
| --- | --- |
| [Execute Query](/how-to/execute-query) | For statements that return rows. The result is a list of objects. |
| [Execute Command](/how-to/execute-command) | For inserts, updates, deletes and other changes. The result is the number of affected rows. |
