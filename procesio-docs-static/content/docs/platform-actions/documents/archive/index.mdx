title: "Archive"

description: "Compress and extract file archives inside a process."
---

The **Documents › Archive** folder packs files into an archive and extracts them back out.

| Action | What it does |
| --- | --- |
| [Zip](/how-to/zip) | Compresses a list of files into one `.zip` archive. |
| [Unzip](/how-to/unzip) | Extracts the files from a `.zip` archive, with an optional password. |
| [Untar](/how-to/untar) | Extracts the files from a `.tar` archive. |
| [Unrar](/how-to/unrar) | Extracts the files from a `.rar` archive. |
