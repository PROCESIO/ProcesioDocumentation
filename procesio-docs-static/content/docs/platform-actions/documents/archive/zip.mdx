**Zip** packs a list of files into a single `.zip` archive. Use it to send several files as one attachment, or to make a large export smaller before you upload it.

## Add the action [#add-the-action]
In the Process Designer toolbox, open **Documents › Archive** and pick **Zip** (or type *Zip* in the search box).

![The Zip action properties: File List, Archive Name and Archive](/images/docs/actions/documents-archive-zip/panel.png)

## Inputs and outputs [#inputs-and-outputs]
| Field | Direction | Type | Required | What to put / what you get |
| --- | --- | --- | --- | --- |
| **File List** | Input | List of File | Yes | The files to put in the archive. |
| **Archive Name** | Input | Text | Yes | The archive name **without** the extension, for example `invoices`. |
| **Archive** | Output | File | Yes | The `.zip` file that holds all the files. |

## Example [#example]
| File List | Archive Name | Archive |
| --- | --- | --- |
| `hello.txt`, `data.json` | `bundle` | `bundle.zip` with both files at its root |
| `hello.txt` | `bundle.zip` | `bundle.zip.zip` |

## Good to know [#good-to-know]
- The action always adds `.zip` to **Archive Name**. Do not type the extension yourself, or you get a name such as `bundle.zip.zip`.
- Every file goes to the root of the archive under its own name. The archive has no folders.
- An empty or missing list makes the step fail with "Input error: Input list of files is null or empty.".
- The archive has no password. To extract an archive, use [Unzip](/how-to/unzip).
