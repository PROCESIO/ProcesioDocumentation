**Unzip** opens a `.zip` archive and gives you the files inside it as a list. Use it when you receive a zipped export by email, from an SFTP server or from an API and need to process each file.

## Add the action [#add-the-action]
In the Process Designer toolbox, open **Documents › Archive** and pick **Unzip** (or type *Unzip* in the search box).

![The Unzip action properties: Archive, Password and File List](/images/docs/actions/documents-archive-unzip/panel.png)

## Inputs and outputs [#inputs-and-outputs]
| Field | Direction | Type | Required | What to put / what you get |
| --- | --- | --- | --- | --- |
| **Archive** | Input | File | Yes | The `.zip` file to extract. |
| **Password** | Input | Text | No | The archive password. Leave it empty for an archive without a password. |
| **File List** | Output | List of File | Yes | The extracted files. |

## Example [#example]
An archive `bundle.zip` that holds `a.txt` and a folder `docs` with `b.txt`:

| Case | Result |
| --- | --- |
| Archive `bundle.zip` | **File List** `a.txt`, `docsb.txt` |
| A password-protected archive, Password `secret` | The files are extracted |
| A password-protected archive, Password empty | The step fails: "Zip extraction error : No password supplied for encrypted zip." |
| Archive `bundle.tar` | The step fails: "Input error: Archive must have '.zip' extension." |

## Good to know [#good-to-know]
- The file name must end in `.zip`. A zip file with another extension is refused, even if its content is a valid zip.
- Folders are not kept. A file in a sub-folder comes out at the top level, and its name is the folder name and the file name joined without a separator (`docs/b.txt` becomes `docsb.txt`). Empty folders are skipped.
- Use a [For Each](/how-to/for-each) to work with the extracted files one by one.
