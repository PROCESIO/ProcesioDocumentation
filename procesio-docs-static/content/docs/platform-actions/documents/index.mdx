The **Documents** folder of the Process Designer toolbox holds the actions that write files, read them back, fill Word templates and pack or unpack archives.

| Action | What it does |
| --- | --- |
| [Word Mail Merge](/how-to/word-mail-merge) | Fills the mail merge fields of a `.docx` template, optionally as PDF. |
| [Object To File](/how-to/object-to-file) | Writes a text or an object into a new file. |
| [List To File](/how-to/list-to-file) | Writes the items of a list one after another into a new file. |
| [File To String](/how-to/read-file) | Reads the content of a text file into a text variable. |
| [Read Files Content](/how-to/read-files-content) | Reads several text files at once, one entry per file. |
| [Read MSG File](/how-to/read-msg-file) | Reads an Outlook `.msg` email: subject, body, metadata and attachments. |
| **Archive** › [Zip](/how-to/zip), [Unzip](/how-to/unzip), [Untar](/how-to/untar), [Unrar](/how-to/unrar) | Compress files into a `.zip`, or extract `.zip`, `.tar` and `.rar` archives. |

Related folders: **Base64** ([File To Base64](/how-to/file-to-base64), [Base64 To File](/how-to/base64-to-file)) and **Excel** ([Export To CSV](/how-to/export-to-csv), [Export To XLSX](/how-to/export-to-xlsx)). To build a document from a template designed in PROCESIO, use [Generate Document](/how-to/generate-document).
