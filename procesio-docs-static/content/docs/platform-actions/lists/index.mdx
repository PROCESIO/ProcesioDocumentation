The **List** folder of the Process Designer toolbox holds the actions that work on lists: simple lists of text, numbers or true/false values, and lists of data models (JSON objects). Lists are entered as JSON, for example `[1,2,3]` or `["a","b"]`. Unless a page says otherwise, positions (indexes) start at `0`.

## Numeric [#numeric]
| Action | What it does |
| --- | --- |
| [Sum](/how-to/sum) | Adds up all the numbers of a list. |
| [Max](/how-to/max) | Returns the largest number. |
| [Min](/how-to/min) | Returns the smallest number. |
| [Median](/how-to/median) | Returns the middle value. |
| [Arithmetic Mean](/how-to/arithmetic-mean) | Returns the average. |

## Read and change a list [#read-and-change-a-list]
| Action | What it does |
| --- | --- |
| [Add](/how-to/list-add) | Appends an element to the end of a list. |
| [Remove](/how-to/remove) | Removes the first occurrence of a value. |
| [Contains](/how-to/list-contains) | Returns `true` if the list contains a value. |
| [Get Index](/how-to/get-index) | Returns the position of a value, or `-1`. |
| [Get Element](/how-to/get-element) | Returns the element at a position. |
| [Has Elements](/how-to/has-elements) | Fails the step if the list is empty. |
| [Length](/how-to/length) | Returns the number of elements. |
| [Sublist](/how-to/sublist) | Returns a slice of the list. |
| [First N Elements](/how-to/first-n-elements) | Returns the first N elements, optionally sorted. |
| [Last N Elements](/how-to/last-n-elements) | Returns the last N elements, optionally sorted. |
| [Concatenate](/how-to/concatenate) | Joins two lists into one. |
| [List To String](/how-to/list-tostring) | Converts a list to JSON text. |

## Sort, filter and clean up [#sort-filter-and-clean-up]
| Action | What it does |
| --- | --- |
| [Sort](/how-to/sort) | Sorts a simple list ascending or descending. |
| [Sort Data Model](/how-to/sort-data-model) | Sorts a list of data models by one or more fields. |
| [Simple Filter](/how-to/simple-filter) | Filters a simple list with one rule. |
| [Filter](/how-to/filter) | Filters a list of data models with field rules. |
| [DeDuplicate](/how-to/deduplicate) | Finds duplicates in a simple list. |
| [Find Duplicates](/how-to/find-duplicates) | Finds duplicate records in a list of data models. |
| [Similarity Search](/how-to/similarity-search) | Finds the values most similar to a text. |
