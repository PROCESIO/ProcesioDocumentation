---
title: "List To String"
icon: "📕"
description: "Converts a list of any type (numbers, text, objects, data models) into its JSON text."
---

The **List To String** action turns a list into a single text value: the list written as JSON. Use it to put a list in an email body, a log message, a file or an API body that expects text.

## Add the action [#add-the-action]
In the Process Designer toolbox, open **List** and pick **List To String** (or type *List To String* in the search box).

![The List To String action properties: Input list and Result](/images/docs/actions/list-list-to-string/panel.png)

## Inputs and outputs [#inputs-and-outputs]
| Field | Direction | Type | Required | What to put / what you get |
| --- | --- | --- | --- | --- |
| **Input list** | Input | List of any type | Yes | The list to convert. It can be a simple list or a list of data models. |
| **Result** | Output | Text | Yes | The list as compact JSON text. |

## Example [#example]
| Input list | Result |
| --- | --- |
| `[1,"a",true,null]` | `[1,"a",true,null]` |
| `[{"book":"Wings of Fire","year":2012},{"book":"The Hidden Kingdom","year":2013}]` | `[{"book":"Wings of Fire","year":2012},{"book":"The Hidden Kingdom","year":2013}]` |
| `["2024-01-05T10:00:00Z",1.5]` | `["2024-01-05T10:00:00Z",1.5]` |
| `[]` | `[]` |

## Good to know [#good-to-know]
- The text is compact JSON: no spaces or line breaks, text values in double quotes, numbers and true/false without quotes.
- An empty list, or a list variable with no value, gives the text `[]`.
- To join text values with a separator instead (for example `a, b, c`), use the String **Join** action.
