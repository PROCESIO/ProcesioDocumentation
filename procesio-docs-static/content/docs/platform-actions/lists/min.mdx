The **Min** action returns the smallest value in a list of numbers. Use it to find the lowest price, score or quantity in a list.

## Add the action [#add-the-action]
In the Process Designer toolbox, open **List**, then **Numeric**, and pick **Min** (or type *Min* in the search box).

![The Min action properties: Input a list of numbers and Result](/images/docs/actions/list-numeric-min/panel.png)

## Inputs and outputs [#inputs-and-outputs]
| Field | Direction | Type | Required | What to put / what you get |
| --- | --- | --- | --- | --- |
| **Input a list of numbers** | Input | List of numbers | Yes | The numbers to compare, for example `[3,-7,12,5]`. |
| **Result** | Output | Number | Yes | The smallest number in the list. |

## Example [#example]
| Input a list of numbers | Result |
| --- | --- |
| `[3,-7,12,5]` | `-7` |
| `[0.5,2,-1.25]` | `-1.25` |
| `[]` (empty list) | The step fails: *The input was not valid, please revise it.* |

## Good to know [#good-to-know]
- Numbers stored as text (`"3"`) are compared as numbers.
- The step fails on an empty list. If the list can be empty, check it first with [Has Elements](/how-to/has-elements) or [Length](/how-to/length).
- Any element that is not a number makes the step fail with *The input was not a number. Please try again.*
