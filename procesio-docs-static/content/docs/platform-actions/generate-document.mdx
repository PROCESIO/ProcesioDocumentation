After creating your [template](/document-template-creation), use it in a process with the **Generate Document** action to produce a filled-in file.

1. Open the [Process Designer](/your-first-process) and create your process.
2. Give it a name.
3. Drag the **Generate Document** action onto the canvas.

   ![](/images/docs/nmeiefzUvY3AM3fElZaXb_image.png)
4. Create the [process variables](/working-with-process-variables) the action needs:
   - **fileout** ➜ an **output** variable of type **File**, to receive the generated document.
   - **htmlstring** ➜ an **output** variable of type **String**, to receive the generated HTML.
   - **Name** ➜ an **input** variable of type **String**, one example of data you'll feed into the template.

   ![](/images/docs/KrXNIFDicVNgys03wwWoE_image.png)
5. Click the **Generate Document** action to configure it:
   - **Select Document Template** — pick the template you created.
   - **Save document as** — **PDF** or **HTML**.
   - **File Name** — the name of the generated file.
   - **Document Output** — bind the **fileout** variable.
   - **HTML string** — bind the **htmlstring** variable.

   ![The Generate Document action properties: Select Document Template, Save document as, File Name, Document Output, HTML string and Map Document Data](/images/docs/actions/generate-document/panel.png)
6. Click **Map Document Data** and map each template variable to a process variable or a typed value — the **Name** input variable created in the process, for example, to the **Name** variable used in the template (they don't need to have the same name). See [Using the template](/using-the-template#using-the-template) for the full mapping reference, including Data Model attributes and list-bound tables.

   ![](/images/docs/x-pyBGITBEVflCYZVXBPT_image.png)
7. **Save**, **Validate** and **Run** the process.
8. Running asks for the process's input variable values.

   ![](/images/docs/N_6SmQ_YMbwJXzmyyT5Zr_image.png)
9. Click **Run**, then **Check instance** to see the run's output.
10. Click the download button to get the generated file or the HTML output.

    ![](/images/docs/LbYMjo5gUlU6owQGiucm2_image.png)

## Good to know [#good-to-know]
- The file extension (`.pdf` or `.html`) is added to **File Name** if it is missing.
- **HTML string** is filled for both PDF and HTML, so you can use it directly, for example as the **Body** of a [Send Email](/how-to/send-email) with **Body is Html** ticked. In this output, double quotes (`"`) are replaced with single quotes (`'`); the generated file keeps them as written.
- Table headers in the template cannot be bound to lists or data models; the step fails with *"Please ensure no list data types are present in the table headers."* or *"Please ensure no data models are present in the table headers."*
