The **Extract List** action (previously called **JSON Mapper To List**) reads a JSON object, a JSON array or a data model and returns every value that matches a [JSONPath](https://goessner.net/articles/JsonPath/) query, as a list.

## Add the action [#add-the-action]
In the Process Designer toolbox, open **To be decommissioned** and pick **Extract List**. Existing processes that already use it keep working.

![The Extract List action properties: Input JSON, Query and Result](/images/docs/actions/to-be-decommissioned-extract-list/panel.png)


## Inputs and outputs [#inputs-and-outputs]
| Field | Direction | Type | Required | What to put / what you get |
| --- | --- | --- | --- | --- |
| **Input JSON** | Input | JSON | Yes | The JSON object, JSON array or data model to read. |
| **Query** | Input | Text | Yes | A JSONPath expression, for example `$..name`. |
| **Result** | Output | List of any type | Yes | Every value that matches the query. |

## Example [#example]
**Input JSON** `[{"name":"Eric","amount":122.45},{"name":"Chris","amount":144.99}]`, **Query** `$..name` → **Result** `["Eric", "Chris"]`.

More JSONPath queries you can use (on a store document like the one in the [Extract Objects](/how-to/extract-object) example):
- `$..book[-1:]`: the last book
- `$..book[0,1]`: the first two books
- `$..book[?(@.isbn)]`: every book that has an `isbn`
- `$..book[?(@.price < 10)]`: every book cheaper than 10
