**Temperature Converter** converts a temperature from one scale to another: Celsius, Fahrenheit, Kelvin or Rankine. Use it when sensor data, a supplier or an API uses a different scale from the one you report in.

## Add the action [#add-the-action]
In the Process Designer toolbox, open **Community-Made** and pick **Temperature Converter** (or type *Temperature Converter* in the search box).

![The Temperature Converter action properties: Temperature, From, To and Converted Temperature](/images/docs/actions/community-made-temperature-converter/panel.png)

## Inputs and outputs [#inputs-and-outputs]
| Field | Direction | Type | Required | What to put / what you get |
| --- | --- | --- | --- | --- |
| **Temperature** | Input | Number (decimal) | Yes | The temperature to convert. Use a dot for decimals. |
| **From** | Input | Option list | Yes | The scale of **Temperature**: **Celsius**, **Fahrenheit**, **Kelvin** or **Rankine**. |
| **To** | Input | Option list | Yes | The scale you want. |
| **Converted Temperature** | Output | Number (decimal) | Yes | The converted temperature. |

## Example [#example]
| Temperature | From | To | Converted Temperature |
| --- | --- | --- | --- |
| `100` | Celsius | Fahrenheit | `212` |
| `98.6` | Fahrenheit | Celsius | `37` |
| `36.6` | Celsius | Fahrenheit | `97.88` |
| `-40` | Celsius | Fahrenheit | `-40` |
| `0` | Celsius | Kelvin | `273.15` |
| `32` | Fahrenheit | Celsius | `0` |

## Good to know [#good-to-know]
- The calculation uses limited precision, so some results carry a tiny error in the last digits (`1` Kelvin to Rankine gives `1.8000488` instead of `1.8`). Pass the result through [Round](/how-to/round) when you need a clean value.
- An empty **Temperature** is treated as `0` (empty Celsius to Kelvin gives `273.15`). Make sure the input is filled.
- Text that is not a number stops the step with an error.
