**List Standard Deviation** measures how spread out a list of numbers is around its average. A small value means the numbers are close to the average; a large one means they vary a lot. Use it to spot unusual values, for example orders far above the usual amount.

## Add the action [#add-the-action]
In the Process Designer toolbox, open **Community-Made** and pick **List Standard Deviation** (or type *List Standard Deviation* in the search box).

![The List Standard Deviation action properties: List of numbers and Standard deviation](/images/docs/actions/community-made-list-standard-deviation/panel.png)

## Inputs and outputs [#inputs-and-outputs]
| Field | Direction | Type | Required | What to put / what you get |
| --- | --- | --- | --- | --- |
| **List of numbers** | Input | List of Number (decimal) | Yes | The numbers. Map a list variable. |
| **Standard deviation** | Output | Number (decimal) | Yes | The standard deviation. |

## Example [#example]
| List of numbers | Standard deviation |
| --- | --- |
| `[2, 4, 4, 4, 5, 5, 7, 9]` | `2` |
| `[1.5, 2.5, -3]` | `2.392116682401221` |
| `[5]` | `0` |
| `[]` | step fails: `Input Error: The list of numbers can't be empty !` |

## Good to know [#good-to-know]
- This is the **population** standard deviation: the sum of squared differences from the average is divided by the number of values (*n*), not by *n − 1*. If you need the sample standard deviation (as in Excel `STDEV.S`), multiply the result by the square root of n / (n − 1).
- The standard deviation is the square root of the [variance](/how-to/list-variance).
