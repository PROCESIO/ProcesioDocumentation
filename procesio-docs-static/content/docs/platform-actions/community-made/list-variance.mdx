**List Variance** measures how spread out a list of numbers is: the average of the squared differences from the mean. Use it with [List Standard Deviation](/how-to/list-standard-deviation) to analyse amounts, durations or scores.

## Add the action [#add-the-action]
In the Process Designer toolbox, open **Community-Made** and pick **List Variance** (or type *List Variance* in the search box).

![The List Variance action properties: List of numbers and Variance](/images/docs/actions/community-made-list-variance/panel.png)

## Inputs and outputs [#inputs-and-outputs]
| Field | Direction | Type | Required | What to put / what you get |
| --- | --- | --- | --- | --- |
| **List of numbers** | Input | List of Number (decimal) | Yes | The numbers. Map a list variable. |
| **Variance** | Output | Number (decimal) | Yes | The variance. |

## Example [#example]
| List of numbers | Variance |
| --- | --- |
| `[2, 4, 4, 4, 5, 5, 7, 9]` | `4` |
| `[]` | step fails: `Input Error: The list of numbers can't be empty !` |

## Good to know [#good-to-know]
- This is the **population** variance: the sum of squared differences is divided by the number of values (*n*), not by *n − 1*. For the sample variance (as in Excel `VAR.S`), multiply the result by n / (n − 1).
- The variance is in squared units (for amounts in EUR, the variance is in EUR²). Use [List Standard Deviation](/how-to/list-standard-deviation) for a value in the original unit.
