The **Community-Made** folder holds actions shared by the PROCESIO community, ready to drop into your processes.

| Action | What it does |
| --- | --- |
| [Timezone Converter](/how-to/timezone-converter) | Converts a date and time from one time zone to another. |
| [Temperature Converter](/how-to/temperature-converter) | Converts a temperature between Celsius, Fahrenheit, Kelvin and Rankine. |
| [List Intersection](/how-to/list-intersection) | Returns the items found in both of two lists. |
| [List Difference](/how-to/list-difference) | Returns the items of the first list that are not in the second. |
| [List Mode](/how-to/list-mode) | Returns the most frequent item of a list. |
| [List Standard Deviation](/how-to/list-standard-deviation) | Computes the standard deviation of a list of numbers. |
| [List Variance](/how-to/list-variance) | Computes the variance of a list of numbers. |
| [List Correlation](/how-to/list-correlation) | Computes the correlation coefficient between two lists of numbers. |
