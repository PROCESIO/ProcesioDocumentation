title: "List Correlation"
icon: "⭐"
description: "Computes the correlation coefficient between two lists of numbers."
---

**List Correlation** tells you how strongly two lists of numbers move together, as a number between `-1` and `1` (the Pearson correlation coefficient). `1` means they rise together, `-1` means one falls when the other rises, and `0` means there is no linear link. Use it, for example, to check whether advertising spend and sales go together.

## Add the action [#add-the-action]
In the Process Designer toolbox, open **Community-Made** and pick **List Correlation** (or type *List Correlation* in the search box).

![The List Correlation action properties: First list, Second list and Correlation coefficient](/images/docs/actions/community-made-list-correlation/panel.png)

## Inputs and outputs [#inputs-and-outputs]
| Field | Direction | Type | Required | What to put / what you get |
| --- | --- | --- | --- | --- |
| **First list** | Input | List of Number (decimal) | Yes | The first series. Map a list variable. |
| **Second list** | Input | List of Number (decimal) | Yes | The second series, with the same number of values, in matching order. |
| **Correlation coefficient** | Output | Number (decimal) | Yes | A value from `-1` to `1`. |

## Example [#example]
| First list | Second list | Correlation coefficient |
| --- | --- | --- |
| `[1, 2, 3, 4, 5]` | `[2, 4, 6, 8, 10]` | `1` |
| `[1, 2, 3]` | `[3, 2, 1]` | `-1` |
| `[1, 2, 3, 4]` | `[2, 1, 4, 3]` | `0.6` |
| `[1, 2, 3]` | `[5, 5, 5]` | empty |
| `[1, 2, 3]` | `[1, 2]` | step fails: `Input Error: The lists must have the same length !` |

## Good to know [#good-to-know]
- The values are paired by position: the first value of one list goes with the first value of the other.
- If all values of a list are the same, there is no correlation to compute and the result is empty. The step does not fail, so check the result before you use it.
- Empty lists stop the step with `Input Error: The first list of numbers can't be empty !` (or *second*).
