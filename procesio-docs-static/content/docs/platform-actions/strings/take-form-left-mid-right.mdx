The **String** folder has three actions that cut a piece out of a text by position. Pick the one that matches where the piece is:

| Action | What it returns | Inputs |
| --- | --- | --- |
| [Take From Left](/how-to/take-from-left) | The first *n* characters. `Hello world`, `5` → `Hello` | **Input String**, **Number of characters** |
| [Take From Middle](/how-to/take-from-middle) | *n* characters starting at a position (counted from `0`). `Hello world`, `6`, `5` → `world` | **Input String**, **Index starting at**, **Extract length** |
| [Take From Right](/how-to/take-from-right) | The last *n* characters. `Hello world`, `5` → `world` | **Input String**, **Number of characters** |

<Callout type="info">
These actions were previously called **String Left**, **String Mid** and **String Right**.
</Callout>

## Good to know [#good-to-know]
- Asking for more characters than the text has is safe: you get what is there.
- In **Take From Middle**, the start position must be inside the text, otherwise the step fails.
- To take everything from a position to the end, use [Substring](/how-to/substing). To find the position of a marker first, use [Get Index](/how-to/string-get-index).
