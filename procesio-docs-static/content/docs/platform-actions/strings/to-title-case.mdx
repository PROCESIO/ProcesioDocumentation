---

**To Title Case** makes the first letter of every word uppercase, for example to tidy up names or headings typed in lowercase.

## Add the action [#add-the-action]
In the Process Designer toolbox, open **String** and pick **To Title Case** (or type *To Title Case* in the search box).

![The To Title Case action properties: Input String and Result](/images/docs/actions/string-to-title-case/panel.png)

## Inputs and outputs [#inputs-and-outputs]
| Field | Direction | Type | Required | What to put / what you get |
| --- | --- | --- | --- | --- |
| **Input String** | Input | Text | Yes | The text to convert. |
| **Result** | Output | Text | Yes | The text with every word capitalized. |

## Example [#example]
| Input String | Result |
| --- | --- |
| `the QUICK brown fox from new york` | `The QUICK Brown Fox From New York` |
| `ana maria POPESCU` | `Ana Maria POPESCU` |
| `hELLO of and` | `Hello Of And` |
| `ștefan cel mare` | `Ștefan Cel Mare` |
| `o'neil's well-known e-mail` | `O'neil's Well-Known E-Mail` |

## Good to know [#good-to-know]
- **Words written entirely in uppercase stay in uppercase** (they are treated as acronyms). To capitalize them too, run the text through [To Lower](/how-to/to-lower) first.
- The other letters of a word are made lowercase: `hELLO` becomes `Hello`.
- A letter after a hyphen starts a new word; a letter after an apostrophe does not.
- Short words such as `of` or `and` are capitalized too.
