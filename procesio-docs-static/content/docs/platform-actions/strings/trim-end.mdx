title: "Trim End"
icon: "📕"
description: "Removes spaces, tabs and line breaks from the end of a text."
---

**Trim End** removes the white space (spaces, tabs, line breaks) at the end of a text. The start of the text and the spaces inside it stay as they are. It is handy for removing a trailing line break from a value read from a file.

## Add the action [#add-the-action]
In the Process Designer toolbox, open **String** and pick **Trim End** (or type *Trim End* in the search box).

![The Trim End action properties: Input String and Result](/images/docs/actions/string-trim-end/panel.png)

## Inputs and outputs [#inputs-and-outputs]
| Field | Direction | Type | Required | What to put / what you get |
| --- | --- | --- | --- | --- |
| **Input String** | Input | Text | Yes | The text to clean. |
| **Result** | Output | Text | Yes | The text without trailing white space. |

## Example [#example]
| Input String | Result |
| --- | --- |
| `   hello world   ` | `   hello world` (leading spaces kept) |

## Good to know [#good-to-know]
- White space means spaces, tabs, new lines, carriage returns and other Unicode spaces such as the non-breaking space.
