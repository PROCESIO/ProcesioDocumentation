---
title: "Replace"
icon: "📕"
description: "Replaces every occurrence of a text inside another text, with or without matching letter case."
---

**Replace** searches a text for a value and returns a new text in which every occurrence of that value is replaced. Use it to swap a word in a template, remove a character, or clean up a value before you store it.

## Add the action [#add-the-action]
In the Process Designer toolbox, open **String** and pick **Replace** (or type *Replace* in the search box).

![The Replace action properties: Source String, Search String, Replacement String, Ignore Case and Result](/images/docs/actions/string-replace/panel.png)

## Inputs and outputs [#inputs-and-outputs]
| Field | Direction | Type | Required | What to put / what you get |
| --- | --- | --- | --- | --- |
| **Source String** | Input | Text | Yes | The text to search and change. |
| **Search String** | Input | Text | Yes | The text to look for. It cannot be empty. |
| **Replacement String** | Input | Text | No | The text to put in its place. Leave it empty to delete every occurrence. |
| **Ignore Case** | Input | Boolean (true/false) | No | Tick it to match the search text in any letter case. Off by default. |
| **Result** | Output | Text | Yes | The text after all replacements. |

## Example [#example]
| Source String | Search String | Replacement String | Ignore Case | Result |
| --- | --- | --- | --- | --- |
| `This is a cat. The cat sleeps.` | `cat` | `dog` | off | `This is a dog. The dog sleeps.` |
| `Cat cat CAT` | `cat` | `dog` | off | `Cat dog CAT` |
| `Cat cat CAT` | `cat` | `dog` | on | `dog dog dog` |
| `a-b-c` | `-` | *(empty)* | off | `abc` |
| `abc` | `z` | `x` | off | `abc` |

## Good to know [#good-to-know]
- **Every occurrence is replaced**, not only the first one.
- **Case-sensitive unless you tick Ignore Case.**
- **An empty Search String fails the step** with *"The value cannot be an empty string. (Parameter 'oldValue')"*.
- If the search text is not found, **Result** is the unchanged source text; the step does not fail.
- The search text is plain text. To replace by a pattern (all digits, any email address…), use [RegEx Replace](/how-to/regex-replace).
