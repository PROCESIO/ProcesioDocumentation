---
title: "To Upper"
icon: "📕"
description: "Converts every letter of a text to uppercase."
---

**To Upper** returns a copy of a text with every letter in uppercase. Use it to normalise codes, country codes or names before you compare or store them.

## Add the action [#add-the-action]
In the Process Designer toolbox, open **String** and pick **To Upper** (or type *To Upper* in the search box).

![The To Upper action properties: Input String and Result](/images/docs/actions/string-to-upper/panel.png)

## Inputs and outputs [#inputs-and-outputs]
| Field | Direction | Type | Required | What to put / what you get |
| --- | --- | --- | --- | --- |
| **Input String** | Input | Text | Yes | The text to convert. |
| **Result** | Output | Text | Yes | The same text in uppercase. |

## Example [#example]
| Input String | Result |
| --- | --- |
| `Hello, ștefan! straße 123` | `HELLO, ȘTEFAN! STRAßE 123` |
| `istanbul` | `ISTANBUL` |

## Good to know [#good-to-know]
- Letters with diacritics keep them (`ș` → `Ș`). Digits and punctuation do not change.
- The German `ß` stays `ß`; it is not turned into `SS`.
