---
title: "Between"
icon: "📕"
description: "Finds every piece of text that sits between a start string and an end string, and returns them as a list."
---

**Between** looks through a text and returns every piece that sits between a start string and an end string, for example every value between `[` and `]`, or every word between two tags. Use it to pull values out of a template, an email body or a log line without writing a regular expression.

<Callout type="info">
Between was previously called **String Between**.
</Callout>

## Add the action [#add-the-action]
In the Process Designer toolbox, open **String** and pick **Between** (or type *Between* in the search box).

![The Between action properties: String to search in, Start string, End string, the two Include checkboxes and List of found strings](/images/docs/actions/string-between/panel.png)

## Inputs and outputs [#inputs-and-outputs]
| Field | Direction | Type | Required | What to put / what you get |
| --- | --- | --- | --- | --- |
| **String to search in** | Input | Text | Yes | The text to search. |
| **Start string** | Input | Text | Yes | The text that marks the start of each piece. |
| **End string** | Input | Text | Yes | The text that marks the end of each piece. |
| **Include start string in the result** | Input | Boolean (true/false) | No | Tick it to keep the start string at the beginning of every result. Off by default. |
| **Include end string in the result** | Input | Boolean (true/false) | No | Tick it to keep the end string at the end of every result. Off by default. |
| **List of found strings** | Output | List of Text | Yes | Every piece found, in the order it appears. An empty list when nothing is found. |

## Example [#example]
| String to search in | Start string | End string | Include start / end | List of found strings |
| --- | --- | --- | --- | --- |
| `Order [A12] and order [B7] shipped` | `[` | `]` | off / off | `["A12", "B7"]` |
| `Order [A12] and order [B7] shipped` | `[` | `]` | on / on | `["[A12]", "[B7]"]` |
| `no brackets here` | `[` | `]` | off / off | `[]` |
| `Name: Ana; name: Ion;` | `name: ` | `;` | off / off | `["Ion"]` |
| `a-1-2-3-b` | `-` | `-` | off / off | `["1", "2", "3"]` |
| `"one" and "two"` | `"` | `"` | off / off | `["one", " and ", "two"]` |

## Good to know [#good-to-know]
- **The search is case-sensitive.** `name: ` does not match `Name: ` (see the fourth example).
- **Each result is the shortest piece** between a start string and the next end string.
- **The same string can be a start and an end.** A string that closes one piece can also open the next, so when the start and end strings are the same you also get the text *between* the pairs (last two examples).
- **A piece cannot span several lines.** In `<b>one` + new line + `two</b> <b>three</b>` only `three` is found. Use [RegEx Extract](/how-to/regex-extract) for text that spans lines.
- Start and end strings are matched as plain text: characters such as `.`, `*`, `(` or `[` have no special meaning.
