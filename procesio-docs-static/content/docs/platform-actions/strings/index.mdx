The **String** folder of the Process Designer toolbox holds the actions that work on text. Its **RegEx** subfolder works with regular expressions, and its **URLs** subfolder encodes and decodes text for URLs.

Most of these actions are case-sensitive and count positions from `0`. Each page says how its action handles letter case, empty values and positions.

## Check a text [#check]
| Action | What it does |
| --- | --- |
| [Contains](/how-to/string-contains) | Checks whether a text contains another text, optionally ignoring case. |
| [Starts With](/how-to/starts-with) | Checks whether a text starts with another text. |
| [Ends With](/how-to/ends-with) | Checks whether a text ends with another text. |
| [Null Or Empty](/how-to/null-or-empty) | Checks whether a text has no value or is empty. |
| [Length](/how-to/string-length) | Returns the number of characters in a text. |
| [Get Index](/how-to/string-get-index) | Returns the position of the first occurrence of a text, or `-1`. |

## Cut a text [#cut]
| Action | What it does |
| --- | --- |
| [Take From Left](/how-to/take-from-left) | Returns the first characters of a text. |
| [Take From Middle](/how-to/take-from-middle) | Returns a piece of a text from a position, with a given length. |
| [Take From Right](/how-to/take-from-right) | Returns the last characters of a text. |
| [Substring](/how-to/substing) | Returns a text from a position to the end. |
| [Between](/how-to/between) | Returns every piece of text between a start and an end string. |
| [Split](/how-to/split) | Splits a text into a list at a separator. |

## Change a text [#change]
| Action | What it does |
| --- | --- |
| [Concatenate](/how-to/string-concatenate) | Joins two texts. |
| [Join](/how-to/string-join) | Joins a list of texts with a separator. |
| [Replace](/how-to/replace) | Replaces every occurrence of a text, optionally ignoring case. |
| [Replace EOL](/how-to/replace-eol) | Converts `\n`, `\r`, `\t` to real line breaks and tabs, or back. |
| [Trim](/how-to/trim) | Removes white space from both ends. |
| [Trim Start](/how-to/trim-start) | Removes white space from the start. |
| [Trim End](/how-to/trim-end) | Removes white space from the end. |
| [To Upper](/how-to/to-upper) | Converts a text to uppercase. |
| [To Lower](/how-to/to-lower) | Converts a text to lowercase. |
| [To Title Case](/how-to/to-title-case) | Capitalizes every word. |
| [To Sentence Case](/how-to/to-sentence-case) | Capitalizes every sentence. |
| [Normalize Diacritics](/how-to/normalize-diacritics) | Removes accents and other diacritical marks. |

## RegEx [#regex]
| Action | What it does |
| --- | --- |
| [RegEx Validate](/how-to/regex-validate) | Checks whether a text matches a regular expression. |
| [RegEx Extract](/how-to/regex-extract) | Returns every match of a regular expression as a list. |
| [RegEx Replace](/how-to/regex-replace) | Replaces every match of a regular expression. |

## URLs [#urls]
| Action | What it does |
| --- | --- |
| [URL Encode](/how-to/url-encode) | Encodes a text for use inside a URL. |
