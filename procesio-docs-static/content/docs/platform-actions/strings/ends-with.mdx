**Ends With** checks whether a text ends with a given value, for example whether a file name ends with `.pdf`. It returns `true` or `false`, so you can use the result in a decision.

## Add the action [#add-the-action]
In the Process Designer toolbox, open **String** and pick **Ends With** (or type *Ends With* in the search box).

![The Ends With action properties: Input String, Input String - End and Result](/images/docs/actions/string-ends-with/panel.png)

## Inputs and outputs [#inputs-and-outputs]
| Field | Direction | Type | Required | What to put / what you get |
| --- | --- | --- | --- | --- |
| **Input String** | Input | Text | Yes | The text to check. |
| **Input String - End** | Input | Text | Yes | The ending to look for. |
| **Result** | Output | Boolean (true/false) | Yes | `true` if **Input String** ends with **Input String - End**, otherwise `false`. |

## Example [#example]
| Input String | Input String - End | Result |
| --- | --- | --- |
| `invoice_2024.pdf` | `.pdf` | `true` |
| `invoice_2024.PDF` | `.pdf` | `false` |
| `abc` | *(empty)* | `true` |

## Good to know [#good-to-know]
- **The check is case-sensitive.** To ignore case, run both values through [To Lower](/how-to/to-lower) first.
- An empty ending always gives `true`.
