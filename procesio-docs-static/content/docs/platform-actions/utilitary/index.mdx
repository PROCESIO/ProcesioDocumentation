The **Utilitary** folder holds small helpers you can use in any process.

| Action | What it does |
| --- | --- |
| [Generate GUID](/how-to/generate-guid) | Creates a new unique identifier. |
| [GUID Converter](/how-to/guid-converter) | Rewrites a GUID as text, hex, a number or Base64, for example to find a row by its GUID with SQL. |
| [Generate Int](/how-to/generate-integer) | Picks a random whole number between two limits. |
| [Generate String](/how-to/generate-string) | Creates random text of the length and character types you choose. |
| [Check Boolean](/how-to/check-boolean) | Stops the process unless a true/false value is the one you expect. |
