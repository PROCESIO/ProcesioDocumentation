---
title: "Generate GUID"
icon: "📕"
description: "Creates a new, random, unique identifier (GUID)."
---

**Generate GUID** creates a new GUID: a 36-character identifier such as `2efaa1e4-8e7a-44c9-81dc-9fc64d270bce` that is, in practice, never generated twice. Use it as a unique reference for a document, an order, a request or a record you create, for example the id of a new Data Store row or a correlation id to send to another system.

## Add the action [#add-the-action]
In the Process Designer toolbox, open **Utilitary** and pick **Generate GUID** (or type *Generate GUID* in the search box).

![The Generate GUID action properties: the Guid output](/images/docs/actions/utilitary-generate-guid/panel.png)

## Inputs and outputs [#inputs-and-outputs]
| Field | Direction | Type | Required | What to put / what you get |
| --- | --- | --- | --- | --- |
| **Guid** | Output | GUID | Yes | Map a GUID variable here. It receives the new identifier. |

The action has no inputs.

## Example [#example]
One run returned **Guid** `2efaa1e4-8e7a-44c9-81dc-9fc64d270bce`. Every run returns a different value.

## Good to know [#good-to-know]
- The GUID is random (version 4). It does not encode a date, an order or a sequence, so do not sort by it to find the newest record.
- To get the GUID as text, or in the hex or Base64 forms a database needs, pass it to [GUID Converter](/how-to/guid-converter).
