---
title: "AWS S3"
icon: "📁"
description: "Actions for working with objects in Amazon S3 buckets."
---

Read, write and organise files stored in S3 straight from a process: upload with **Put Object**, fetch with **Get Object**, check with **Object Exists** and **Get Metadata**, browse with **List Keys** and **List Objects**, and manage what is there with **Copy Object**, **Move Object** and the **Delete** actions.
