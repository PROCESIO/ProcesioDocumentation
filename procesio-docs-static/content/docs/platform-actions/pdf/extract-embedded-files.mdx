The **Extract Embedded Files** action returns the files that are attached inside a PDF. A common case is an electronic invoice (for example ZUGFeRD or Factur-X) that carries its XML data inside the PDF: extract the XML, then read it with the XML actions.

## Add the action [#add-the-action]
In the Process Designer toolbox, open **PDF** and pick **Extract Embedded Files** (or type *Embedded* in the search box).

![The Extract Embedded Files action properties: Pdf file and Embedded files](/images/docs/actions/pdf-extract-embedded-files/panel.png)

## Inputs and outputs [#inputs-and-outputs]
| Field | Direction | Type | Required | What to put / what you get |
| --- | --- | --- | --- | --- |
| **Pdf file** | Input | File | Yes | The PDF to read. |
| **Embedded files** | Output | List of files | Yes | Every attached file, under its attachment name. |

## Example [#example]
| Pdf file | Embedded files |
| --- | --- |
| `with-attachment.pdf`, which carries an attachment `data.csv` | one file: `data.csv` |
| `annex.pdf`, with no attachment | empty |

## Good to know [#good-to-know]
- A PDF without attachments does not fail the step; the output is simply empty. Check it before looping over it.
- Files are named as they were attached. Use [For Each](/how-to/for-each) to handle each file, or pick one by name.
- The input must have the `.pdf` extension, otherwise the step fails with `Pdf file extension should be '.pdf', found => …`.
