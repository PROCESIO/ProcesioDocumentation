title: "Merge Files"

description: "Joins two PDF files into one: the pages of the first file, then the pages of the second."
---

The **Merge Files** action joins two PDF files into a new one, for example an invoice and its annex. The new file holds every page of the first PDF followed by every page of the second.

## Add the action [#add-the-action]
In the Process Designer toolbox, open **PDF** and pick **Merge Files** (or type *Merge Files* in the search box).

![The Merge Files action properties: First Pdf, Second Pdf and Merge Result](/images/docs/actions/pdf-merge-files/panel.png)

## Inputs and outputs [#inputs-and-outputs]
| Field | Direction | Type | Required | What to put / what you get |
| --- | --- | --- | --- | --- |
| **First Pdf** | Input | File | Yes | The PDF whose pages come first. |
| **Second Pdf** | Input | File | Yes | The PDF whose pages come after. |
| **Merge Result** | Output | File | Yes | The merged PDF. |

## Example [#example]
**First Pdf** `invoice.pdf` (3 pages), **Second Pdf** `annex.pdf` (1 page) → **Merge Result** a 4-page PDF named `invoice.pdf_annex.pdf.pdf`.

## Good to know [#good-to-know]
- The output name is built from both input names, extensions included: *first name*`_`*second name*`.pdf`. Rename it with a file action if you need a clean name.
- Both files must have the `.pdf` extension. Otherwise the step fails with `First Pdf extension should be '.pdf', found => …` (or `Second Pdf …`).
- The action merges exactly two files. To merge more, chain several Merge Files actions, or loop over a list and merge the running result with the next file.
