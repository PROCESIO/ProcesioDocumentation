The **Select Pages** action makes a new PDF that contains only the pages you choose, in the order you list them. Use it to split a document, pull out a cover page, or reorder pages.

## Add the action [#add-the-action]
In the Process Designer toolbox, open **PDF** and pick **Select Pages** (or type *Select Pages* in the search box).

![The Select Pages action properties: Input file, Page Selection and Resulting File](/images/docs/actions/pdf-select-pages/panel.png)

## Inputs and outputs [#inputs-and-outputs]
| Field | Direction | Type | Required | What to put / what you get |
| --- | --- | --- | --- | --- |
| **Input file** | Input | File | Yes | The PDF to take pages from. |
| **Page Selection** | Input | Text | Yes | The pages to keep, **one selection per row**. A row is a page number (`3`) or a range (`5-7`). Press Enter between selections. |
| **Resulting File** | Output | File | Yes | A new PDF with the selected pages, in selection order (top row first). |

## Example [#example]
With a 3-page **Input file** `invoice.pdf`:

| Page Selection | Resulting File |
| --- | --- |
| `3` then `1-2` (two rows) | pages 3, 1, 2 |
| `3-1` | pages 3, 2, 1 (a range written backwards gives the pages in reverse order) |
| `1,3` | The step fails: `Invalid selection on row 1 : Bad format. Please use [number] for single page selection or [number]-[number] for interval selection.` |
| `5` | The step fails: `Invalid selection on row 1 : Value 4 is greater than input file page count !` |

The file is named after the input, for example `invoice.pdf_Selection.pdf`.

## Good to know [#good-to-know]
- Pages are numbered from 1.
- Commas, spaces and words are not accepted inside a row: use one row per page or range.
- The same page can be listed more than once; it then appears more than once in the result.
- The input must have the `.pdf` extension.
