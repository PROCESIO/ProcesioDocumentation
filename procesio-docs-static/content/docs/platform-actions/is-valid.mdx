title: "Is Valid"
description: "Four toolbox folders have an Is Valid action. Pick the page for the one you are using: JSON, XML, HTML or PDF."
---

Four folders of the Process Designer toolbox have an action called **Is Valid**. Each checks a different kind of content:

| Toolbox folder | What it checks | How you get the result | Page |
| --- | --- | --- | --- |
| **JSON** | A text is well-formed JSON. | The step succeeds or fails. | [JSON Is Valid](/how-to/json-is-valid) |
| **XML** | A text is well-formed XML and, optionally, valid against an XSD schema. | The step succeeds or fails. | [XML Is Valid](/how-to/xml-is-valid) |
| **HTML** | Every HTML tag is properly closed and nested. | The step succeeds or fails. | [HTML Is Valid](/how-to/html-is-valid) |
| **PDF** | A file is a PDF that can be opened. | Outputs **Validation Output** (true/false) and **Validation Reason**; the step does not fail. | [PDF Is Valid](/how-to/pdf-is-valid) |
