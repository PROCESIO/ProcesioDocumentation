**Rename Sheet** changes the name of one sheet in a workbook.

## Add the action [#add-the-action]
In the Process Designer toolbox, open **Excel** and pick **Rename Sheet** (or type *Rename Sheet* in the search box).

![The Rename Sheet action properties: Excel workbook, Old name and New name](/images/docs/actions/excel-rename-sheet/panel.png)

## Inputs and outputs [#inputs-and-outputs]
| Field | Direction | Type | Required | What to put / what you get |
| --- | --- | --- | --- | --- |
| **Excel workbook** | Input and output | File | Yes | The workbook to change. Pick a File variable: after the step it holds the changed workbook. |
| **Old name** | Input | Text | Yes | The current name of the sheet. |
| **New name** | Input | Text | Yes | The new name. |

## Example [#example]
`orders.xlsx` with the sheets *Orders* and *Empty*, Old name `Empty`, New name `Notes` → the workbook now has *Orders* and *Notes*.

## Good to know [#good-to-know]
- If no sheet has the old name, the step fails with "Excel error: Could not find any sheet named '…' in the current workbook.".
- If another sheet already has the new name, the step fails with "Excel error: A sheet named '…' already exists in the current workbook.".
- **Excel workbook** is both the input and the output; the file keeps its name. Only `.xlsx` and `.xlsm` files are accepted.
