**Delete Sheet** removes one sheet, and everything on it, from a workbook.

## Add the action [#add-the-action]
In the Process Designer toolbox, open **Excel** and pick **Delete Sheet** (or type *Delete Sheet* in the search box).

![The Delete Sheet action properties: Excel workbook and Sheet name](/images/docs/actions/excel-delete-sheet/panel.png)

## Inputs and outputs [#inputs-and-outputs]
| Field | Direction | Type | Required | What to put / what you get |
| --- | --- | --- | --- | --- |
| **Excel workbook** | Input and output | File | Yes | The workbook to change. Pick a File variable: after the step it holds the changed workbook. |
| **Sheet name** | Input | Text | Yes | The name of the sheet to delete. |

## Example [#example]
| Excel workbook | Sheet name | Result |
| --- | --- | --- |
| `orders.xlsx` with *Orders* and *Empty* | `Empty` | The workbook now has only *Orders* |
| the same workbook | `Missing` | The step fails: "Excel error: Could not find any sheet named 'Missing' in the current workbook." |

## Good to know [#good-to-know]
- A workbook must keep at least one sheet. Deleting the last one fails with "Excel Error: Sheet count per workbook can't go lower than 1.".
- **Excel workbook** is both the input and the output; the file keeps its name. Only `.xlsx` and `.xlsm` files are accepted.
