**Create Workbook** makes a new, empty `.xlsx` file with one sheet. Use it as the starting point when your process builds an Excel file step by step with the other Excel actions.

## Add the action [#add-the-action]
In the Process Designer toolbox, open **Excel** and pick **Create Workbook** (or type *Create Workbook* in the search box).

![The Create Workbook action properties: Workbook name, Sheet name and Workbook](/images/docs/actions/excel-create-workbook/panel.png)

## Inputs and outputs [#inputs-and-outputs]
| Field | Direction | Type | Required | What to put / what you get |
| --- | --- | --- | --- | --- |
| **Workbook name** | Input | Text | Yes | The file name. `.xlsx` is added for you. |
| **Sheet name** | Input | Text | Yes | The name of the first (and only) sheet. |
| **Workbook** | Output | File | Yes | The new, empty workbook. |

## Example [#example]
| Workbook name | Sheet name | Workbook |
| --- | --- | --- |
| `report` | `Data` | `report.xlsx` with one empty sheet `Data` |
| `report.xls` | `Data` | `report.xlsx` (the extension is replaced) |

## Good to know [#good-to-know]
- Any extension other than `.xlsx` is replaced with `.xlsx`. Spaces at the start and end of the name are removed.
- To add more sheets, use [Insert Sheet](/how-to/insert-sheet). To fill a workbook from a list in one go, [Export To XLSX](/how-to/export-to-xlsx) is simpler.
