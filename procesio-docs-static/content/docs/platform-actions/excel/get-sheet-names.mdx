---

**Get Sheet Names** gives you the names of every sheet in a workbook, in the order they appear in Excel. Use it to check that a sheet exists before you read it, or to loop over all sheets.

## Add the action [#add-the-action]
In the Process Designer toolbox, open **Excel** and pick **Get Sheet Names** (or type *Get Sheet Names* in the search box).

![The Get Sheet Names action properties: Excel workbook and Sheet names](/images/docs/actions/excel-get-sheet-names/panel.png)

## Inputs and outputs [#inputs-and-outputs]
| Field | Direction | Type | Required | What to put / what you get |
| --- | --- | --- | --- | --- |
| **Excel workbook** | Input | File | Yes | An `.xlsx` or `.xlsm` workbook. |
| **Sheet names** | Output | List of Text | Yes | The sheet names. |

## Example [#example]
| Excel workbook | Sheet names |
| --- | --- |
| `orders.xlsx` with the sheets *Orders* and *Empty* | `["Orders","Empty"]` |
| `people.csv` | The step fails: "Input error: Excel file extension should be '.xlsx' or '.xlsm' [Excel 2007], found => .csv" |

## Good to know [#good-to-know]
- Only `.xlsx` and `.xlsm` files are accepted. Convert an old `.xls` file first with [XLS To XLSX](/how-to/xls-to-xlsx).
