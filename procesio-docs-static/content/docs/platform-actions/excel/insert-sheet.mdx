**Insert Sheet** adds a new, empty sheet at the end of a workbook. Use it to give a report one sheet per month, per customer or per section.

## Add the action [#add-the-action]
In the Process Designer toolbox, open **Excel** and pick **Insert Sheet** (or type *Insert Sheet* in the search box).

![The Insert Sheet action properties: Excel workbook and New sheet](/images/docs/actions/excel-insert-sheet/panel.png)

## Inputs and outputs [#inputs-and-outputs]
| Field | Direction | Type | Required | What to put / what you get |
| --- | --- | --- | --- | --- |
| **Excel workbook** | Input and output | File | Yes | The workbook to change. Pick a File variable: after the step it holds the changed workbook. |
| **New sheet** | Input | Text | Yes | The name of the sheet to add. |

## Example [#example]
| Excel workbook | New sheet | Result |
| --- | --- | --- |
| `orders.xlsx` with *Orders* and *Empty* | `Summary` | The workbook now has *Orders*, *Empty* and *Summary* |
| the same workbook | `Orders` | The step fails: "Excel error: A sheet named 'Orders' already exists in the current workbook." |

## Good to know [#good-to-know]
- **Excel workbook** is both the input and the output: the same variable carries the changed file to the next steps. The file keeps its name.
- Only `.xlsx` and `.xlsm` files are accepted.
- When the step fails, the variable keeps the original, unchanged workbook.
