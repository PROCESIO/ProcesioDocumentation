The [PROCESIO Marketplace](https://procesio.app/FlowZy/Marketplace/Usecases) is a library of use cases built in PROCESIO. Each one is a complete set of processes, forms and data stores that you import and then connect to your own accounts.

This section holds their setup guides. The **Documentation** button on a Marketplace card opens the matching page here.

## Getting a use case

1. Open the [Marketplace](https://procesio.app/FlowZy/Marketplace/Usecases) and find the use case. **Watch demo** shows it running.
2. Click **Get free**. A panel opens on the right.
3. Enter the email and password of your PROCESIO account and click **Login**.
4. Tick the box to accept the Marketplace terms.
5. Click **Import**.

PROCESIO creates a new workspace in your account, named `MarketPlace_` plus a few random characters, and imports the use case there. Your existing workspaces stay as they are.

Would you rather pick the workspace yourself? Click the download icon next to **Import**. You get the `.procesio` file, and [Import / Export resources](/import-export-resources) shows how to bring it in. That route needs an Admin role, and it doesn't work in a Personal workspace.

<Callout type="info">
Imported credentials have no sign-ins or passwords in them. Each guide lists what to fill in after the import, such as a Google sign-in, an email server or an API key.
</Callout>
